# REQ-006 — Локализация UI (RU/EN)

**Приоритет:** Средний
**Источник:** brief

## Requirement

Весь пользовательский текст (команды, меню, status bar, ошибки с подсказками, hover, диагностика, terminal output, webviews) доступен на русском (default) и английском языках. Язык определяется автоматически по `vscode.env.language`, может быть переключён вручную командой и сохраняется в extension-owned settings. При отсутствии перевода — fallback на русский, затем на ключ; без падений.

## Rationale

Требование зафиксировано исходным ТЗ и подтверждено пользователем; RU — язык проекта по умолчанию согласно manifest → language.

## Acceptance

- Переключение языка обновляет все видимые UI-элементы без перезапуска VSCode.
- Отсутствующий перевод не приводит к ошибке в консоли — тихий fallback на RU, затем на ключ.
- Terminal output и webview-диалоги локализованы наравне с обычным UI.
