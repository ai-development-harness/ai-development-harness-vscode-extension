## Findings

### F-001 — Medium (verification/security regression) — valid-input test не доказывает запрет echo обычного free text

**Location:** `tests/integration/commands.test.js:141-176`,
`tests/unit/api/agentDispatcher.test.ts:27-38`, ADR-011 Decision 3,
`planning/tasks/STEP-009.md:46-49,57-58,86-99,573-582`.

Hostile input в обоих durable regressions состоит только из secret-shaped
значений и control bytes: split `token=real-secret` и `xoxb-*`. Assertions
запрещают эти secret values и control characters, а Extension Host test требует
наличие descriptor, но не содержит уникального безопасного prose/sentinel и не
доказывает, что original intent целиком отсутствует в каждом sink.

Конкретная regression остаётся зелёной: dispatcher может по-прежнему вывести
правильный descriptor, а затем дополнительно append/show sanitized исходный
intent. Для текущего fixture sanitization превратит его в значения вроде
`token=[redacted] [redacted]`; descriptor останется в обоих sink, проверяемые
secret/control bytes исчезнут, fake CLI не запустится — все assertions пройдут.
При реальном обычном описании, например `add public roadmap card`, его текст
будет раскрыт, хотя ADR-011 требует never-echo любого original free text, а не
только распознанных credentials.

**Impact:** production implementation текущей revision формирует только safe
descriptor и выглядит корректной, но обязательная regression boundary неполна.
Будущая утечка обычного user intent одновременно с descriptor не будет
обнаружена ни unit, ни Extension Host suite; Evidence о запрете raw free text
завышено, поэтому REQ-005/ADR-011 acceptance пока не доказаны durable test.

**Fix direction:** добавить в valid hostile input отдельный нейтральный
уникальный sentinel, не похожий на secret (например `ordinary-intent-sentinel`),
и для обеих family/RU/EN отрицательно проверить его отсутствие в каждом
Output Channel и notification value. Owning-layer regression также должна
доказать, что ни одна дополнительная строка/param не содержит sentinel;
secret/control/no-spawn assertions сохранить.
