## Findings

### F-001 — Medium (verification/security regression) — safe-handoff не доказан для `PROJECT QUICK FIX`, второй из двух text-command family

**Location:** `src/api/agentDispatcher.ts:78-92`,
`tests/unit/api/agentDispatcher.test.ts:27-54`,
`tests/integration/commands.test.js:125-196`,
`planning/tasks/STEP-009.md:42-49,94-99,536-548`, ADR-011 Decision 3/5.

CTS содержит две required-input family: `STEP ADD:` и `PROJECT QUICK FIX:`.
Production regex и общий Command Palette path сейчас обрабатывают обе, однако
все durable safe-descriptor assertions вызывают только `STEP ADD`: unit test
проверяет RU/EN `manualHandoffLabel()` и hostile sink только для `STEP ADD`, а
Extension Host valid/invalid scenarios вызывают только `harness.addStep`.
`harness.quickFix` проверяется лишь на регистрацию команды; executor matrix
проверяет no-spawn ниже UI boundary и не проверяет descriptor, sinks или
invalid-input path.

Конкретный regression остаётся зелёным: удаление `PROJECT QUICK FIX` из
alternation `manualHandoffLabel()` приведёт к публикации исходной команды через
fallback `sanitizeExternalText(command)`, а обычное не-secret описание попадёт
в Output Channel и notification вместо неисполняемого descriptor. Аналогично
ошибка `inputKind`/wiring `quickFixCommand` может обойти общий invalid-input
blocker, не нарушив существующие assertions.

**Impact:** реализация выглядит корректной сейчас, но Required FIX и
Verification требуют unit и Extension Host evidence для text-command contract,
а одна из двух явно перечисленных command family остаётся недоказанной. Это
оставляет security boundary ADR-011 и REQ-005 без owning regression для
`PROJECT QUICK FIX`; заявленное в Evidence покрытие обеих family завышено.

**Fix direction:** параметризовать unit и Extension Host regressions по
`STEP ADD` / `harness.addStep` и `PROJECT QUICK FIX` / `harness.quickFix`.
Для каждой family доказать RU/EN safe descriptor в обоих sink, отсутствие raw
free text/control bytes и no-spawn; invalid-input matrix должен также пройти
оба Command Palette path и сохранить точный localized blocker.
