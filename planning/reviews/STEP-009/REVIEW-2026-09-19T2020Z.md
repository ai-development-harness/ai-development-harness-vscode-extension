## Findings

### F-001 — Medium (verification/security regression) — normal free text не проверяется отдельно от secret/control payload

**Location:** `tests/integration/commands.test.js:141-179`,
`tests/unit/api/agentDispatcher.test.ts:27-49`, ADR-011 Decision 3,
`planning/tasks/STEP-009.md:46-49,57-58,96-99`.

Нейтральный `ordinary-intent-sentinel` добавлен только внутрь одного смешанного
fixture, который одновременно содержит split credential key, `xoxb-*`, CR/LF,
ANSI и Unicode control bytes. Unit descriptor test также всегда добавляет
`token=real-secret`. Отдельного valid path с чистым обычным описанием нет.

Конкретная regression останется зелёной: implementation может выбирать safe
descriptor только когда detector замечает secret/control payload, а обычный
текст отображать через sanitized exact command. Текущий смешанный fixture
попадёт в безопасную ветку и все assertions пройдут, но реальный ввод вроде
`add public roadmap card` окажется в Output Channel и notification. ADR-011
запрещает echo любого original free text, а не только подозрительного.

**Impact:** Required FIX и Verification не доказывают полный never-echo contract
для нормального пользовательского описания. Будущая оптимизация на основе
redaction/detection может раскрыть intent при зелёных unit и Extension Host
tests.

**Fix direction:** добавить отдельный pure-normal fixture с уникальным
нейтральным sentinel без secret/control fragments. Для `STEP ADD` и `PROJECT
QUICK FIX` на RU/EN провести его через реальный Command Palette path, потребовать
descriptor, отсутствие sentinel в каждом Output Channel/notification value и
отсутствие fake Codex/Claude spawn. Hostile fixture сохранить отдельно.

### F-002 — Medium (verification/localization regression) — EN test не доказывает локализацию полного notification

**Location:** `tests/integration/commands.test.js:158-175,84-117`,
`src/commands/baseCommand.ts:54-59`, REQ-006,
`planning/tasks/STEP-009.md:46-49,88-99`.

Valid text-command E2E требует только, чтобы warning `includes(descriptor)`.
Локализованная внешняя обёртка `harness.agent.manualFallback` целиком не
сравнивается ни на RU, ни на EN. Exact no-text scenario выполняется только при
default RU и также проверяет лишь наличие `STEP FIX STEP-009`.

Конкретная regression останется зелёной: English locale может получить
hardcoded русский manual-fallback wrapper с английским descriptor внутри.
`includes(descriptor)` выполнится, secret/control/no-spawn assertions тоже
пройдут, хотя видимое notification нарушит REQ-006.

**Impact:** обязательная RU/EN regression не защищает весь пользовательский
handoff text; смешанная локализация снова может попасть в основной UI path без
падения suite.

**Fix direction:** для обеих text-family сравнивать полное ожидаемое RU/EN
notification, а не только вложенный descriptor. Exact no-text path также
проверить на RU и EN с полностью локализованной обёрткой, сохраняя exact
protocol command внутри неё.
