## Acceptance observations

- ADR-011 разрешает исходный конфликт без redaction-as-security: exact
  canonical command показывается только для CTS `input=none` и optional input
  без переданного текста. Required input и фактически переданный optional text
  получают локализованный неисполняемый descriptor без raw free text.
- Manual continuation описан однозначно и не создаёт скрытый transport:
  Extension Host не копирует текст в clipboard/terminal, не создаёт child
  process и не навязывает syntax конкретного Codex/Claude CLI; пользователь
  повторно вводит intent в контролируемой им agent session.
- Security guarantee корректно ограничена Extension Host handoff surfaces и
  extension-owned storage. Отдельное хранение raw canonical command механизмом
  Harness Execution Status ради restart semantics раскрыто явно и не выдаётся
  за часть extension handoff boundary.
- ADR-010 Decision 2 superseded только в части visual representation
  free-text command. Manual-only lifecycle, no-context/no-spawn contract и
  границы ADR-007/ADR-008/ADR-009 не ослаблены.
- REQ-005, REQ-006, architecture, ADR index и STEP-009 требуют одинаковую
  RU/EN модель: оба UI sink показывают safe descriptor, invalid input даёт
  actionable blocker, а agent CLI не запускается.
- STEP-009 получил проверяемый follow-up: отдельные unit и Extension Host
  regressions для обоих sink, RU/EN, secret/control input, invalid input и
  no-spawn. Текущие production findings STEP-009 не выданы за закрытые.
