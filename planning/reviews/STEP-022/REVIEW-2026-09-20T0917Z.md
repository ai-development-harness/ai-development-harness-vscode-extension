## Closure предыдущих findings

### F-001 — Closed

`StepLanguageAssociationController.associate()` начинает Promise-chain до
вызова `setTextDocumentLanguage`. Поэтому synchronous throw преобразуется в
локально обработанный rejection, а общий `finally` очищает pending key. Unit
regression доказывает отсутствие throw и успешную повторную попытку.

### F-002 — Closed

Runtime association допускается только для исходного `markdown` документа.
`plaintext` и уже назначенный `harness-step` остаются no-op, поэтому extension
не отменяет явный language mode и не выполняет повторный assignment.

### F-003 — Closed

Focused Extension Host regression запускается в отдельном host, до
`ext.activate()` меняет fixture manifest на `custom/steps`, открывает
`custom/steps/STEP-101.md` как `markdown`, а после activation подтверждает
`harness-step` и diagnostic для `REQ-999`. Это непосредственно доказывает путь
`manifest -> workspace.textDocuments initial sweep -> language assignment ->
provider`. После теста manifest восстановлен в `planning/tasks`, временный
`custom/` каталог отсутствует.
