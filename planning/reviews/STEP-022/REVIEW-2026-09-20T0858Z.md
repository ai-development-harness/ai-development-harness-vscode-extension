## Findings

### F-001 — Medium — Synchronous ошибка `setTextDocumentLanguage` выходит из controller

**Location:** `src/editor/activation.ts:60-64`,
`tests/unit/editor/activation.test.ts:356-366`

**Scenario:** Given canonical STEP document и реализация VS Code API, которая
синхронно бросает ошибку до возврата `Thenable` (например, документ успел стать
недействительным на lifecycle boundary), when `associate()` вызывает
`this.setLanguage(...)`, then исключение возникает до `Promise.resolve` и не
попадает в последующий `.catch()`.

**Impact:** exception покидает `associate()`/event callback, extension не
выполняет обещанное local failure handling, а URI навсегда остаётся в `pending`
до dispose. Текущий regression проверяет только `Promise.reject`, поэтому
заявленное evidence «local error handling» не покрывает этот путь.

**Fix direction:** начинать promise chain до вызова API
(`Promise.resolve().then(() => setLanguage(...))`) либо обернуть сам вызов в
`try/catch`, гарантируя очистку `pending` в обоих путях. Добавить unit regression
с `setLanguage`, который бросает синхронно, и доказать отсутствие throw плюс
возможность безопасной повторной попытки.

### F-002 — Medium — Runtime assignment перехватывает non-Markdown language mode

**Location:** `src/editor/activation.ts:55-56`,
`planning/tasks/STEP-022.md:40-44`, `planning/tasks/STEP-022.md:139-145`

**Scenario:** Given `custom/steps/STEP-101.md` внутри canonical task directory,
но документ открыт с явным language mode, отличным от `markdown` и
`harness-step` (например, `plaintext`), when activation/open/manifest refresh
вызывает `associate()`, then controller всё равно назначает `harness-step`.

**Impact:** реализация выходит за согласованный scope «открытый
Markdown-документ» и расходится с Implementation plan, где non-Markdown
documents должны возвращаться без действия. Она также может отменять явный
пользовательский выбор language mode. Unit matrix покрывает только default
`markdown` и уже назначенный `harness-step`, поэтому regression этого не
обнаруживает.

**Fix direction:** до path/assignment проверять допустимый исходный
`document.languageId` согласно task contract (для runtime association —
`markdown`; `harness-step` остаётся idempotent no-op). Добавить unit case с
`plaintext`/другим language ID и assertion, что API не вызван.
