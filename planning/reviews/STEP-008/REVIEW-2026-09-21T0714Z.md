## Findings

### F-001 — Medium — Extension Host regression не проверяет refresh и click actions

**Location:** `tests/integration/editor.test.js:7-17`,
`src/ui/statusBar.ts:64-65`

Новый тест активирует extension и один раз читает четыре строки через
`getDebugState()`. Он не изменяет STEP/manifest/status file, не ждёт 1000 ms
debounce и не подтверждает, что Status Bar обновился. Test seam возвращает только
text, поэтому тест также не может проверить commands/arguments четырёх items:
открытие manifest, открытие STATUS.md, выполнение предложенной STEP command и
открытие Problems surface.

Assertion для next state допускает одновременно любую строку с `STEP ` и empty
state, поэтому не доказывает точную recommendation текущего fixture или её
изменение после внешней правки.

**Impact:** два ключевых acceptance REQ-004 — обновление при изменении файлов и
действие по клику каждого item — остаются без regression evidence. Поломка
watcher/debounce/command wiring не уронит новый тест.

**Fix direction:** расширить test seam безопасным snapshot commands/arguments;
в Extension Host создать либо изменить controlled STEP fixture, дождаться
debounce и доказать изменение completion/next. Проверить exact commands и target
arguments каждого item. Тест лучше вынести в отдельный Status Bar suite, но имя
файла само по себе verdict не блокирует.
